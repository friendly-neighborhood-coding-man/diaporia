# DIAPORIA

**AI that plans before it acts.**

DIAPORIA is a deliberate multi-model AI system that turns intent into verified plans and controlled execution. You describe what you want done. DIAPORIA works out what it needs to know, builds a plan, verifies the important parts, asks before consequential actions, and confirms what actually happened.

Understand → Plan → Verify → Act → Confirm

## About this repository

This repository hosts DIAPORIA's public website, documentation and release information. The application source is not distributed from this repository.

## Website

https://friendly-neighborhood-coding-man.github.io/diaporia/

To preview locally, serve the repository root with any static file server, for example:

```sh
python3 -m http.server 8000
```

then open http://localhost:8000/. Run `node scripts/check-site.mjs` to check links and external requests before publishing.
